씨름 로봇 2026 - 센서 처리 펌웨어, IRC 2위

새 팀을 꾸려 IRC 지능로봇대회 씨름로봇 부문에 다시 출전해 1점 차이로 2위를 했습니다. 팀에서 센서 값을 처리하는 STM32 펌웨어와 고정 주기 제어 루프를 맡았습니다.

1. 프로젝트 개요

2025년 4위의 경험을 바탕으로, 2026년에는 새 팀원들과 함께 같은 대회(IRC 지능로봇대회 씨름로봇 부문)에 다시 출전했고 1점 차이로 2위를 했습니다. → 전년도 이야기: 씨름 로봇 2025

  • 내 역할: 센서 값을 처리하는 펌웨어, 제어 보드 관련 작업, 시험
  • 팀 역할 분담: 구동(모터 제어) 모듈은 팀원이 맡았습니다.

씨름로봇은 팀마다 전략이 승패를 가르는 종목이라, 알고리즘과 사용 센서, 경기장 세부 내용은 이 글에서 공개하지 않습니다.

2. 펌웨어에서 한 일

  • 고정 주기 제어 루프. RTOS 없이 타이머 신호마다 센서 → 판단 → 구동 → 송신을 한 사이클로 돌리는 구조로, 480Hz로 동작하게 만들었습니다.
  • CPU가 기다리지 않는 구조. 주기가 밀리지 않도록 센서 입력을 DMA와 인터럽트 중심으로 처리했습니다.
  • 센서 값 정리. 여러 센서의 값을 필터링해서 하나의 상태 구조로 통합하고, 센서와 모터의 정상 여부도 함께 표시하도록 했습니다. 판단하는 쪽이 센서의 세부 사항을 몰라도 되게 하는 것이 목적이었습니다.
  • 시험. 제어 루프의 주기를 직접 측정해, 약 12,000회 측정에서 틱 손실 없이 한 틱이 평균 약 2.08ms(480Hz)임을 확인했습니다.

3. 2025년과 달라진 점

2025년에는 연습 때와 경기 때 센서 값이 달라 실점했습니다. 2026년에는 센서 보정과 필터링 구조를 다시 짜서 환경이 달라져도 값이 덜 흔들리게 만드는 데 집중했습니다.

4. 한계

  • 센서 모듈을 정리해 마친 시점(10월 중순)에는 실제 구동 디버깅과 전략 고도화가 아직 진행 중이었습니다.
  • 위 시험은 제어 루프 단독 측정이라, 경기 중 전체 성능을 그대로 보장하지는 않습니다.
