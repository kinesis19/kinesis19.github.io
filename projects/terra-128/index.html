Terra-128 - 토양·지형 조사 로버

YEAR2026
ROLE커스텀 PCB 설계 · 저수준 펌웨어
TEAM2인 팀
CATEGORY회로 설계

RGB-D 카메라, IMU, 초음파, 압력, 토양 수분 센서를 융합해 지형 위험도를 분석하고 토양을 측정하는 탐사 로버. Altium으로 ATmega128 커스텀 제어 PCB를 설계·제작하고, 저수준 펌웨어와 센서 필터를 맡았습니다.

1. 프로젝트 개요

2026년 1학기 ‘AI로봇실험3’ 수업의 2인 팀 프로젝트로 만든 토양·지형 조사 로버 Terra-128 입니다. 농업, 재난 현장, 야외 탐사 환경에서는 지면의 평탄도, 장애물, 토양 상태를 사람이 직접 확인하기 어렵습니다. 흙, 돌, 나무뿌리 같은 장애물이 섞인 지형에서는 거리 센서만으로 주행을 판단하기 어렵기 때문에, 여러 센서를 융합해 지형과 토양 상태를 함께 판단하는 로봇을 목표로 했습니다.

  • 과목: AI로봇실험3 (2026년 1학기)
  • 팀: 2인 팀 (회로·PCB·저수준 펌웨어 / 기구 설계·비전·Python 상위 소프트웨어로 역할 분담)
  • 내 역할: Altium 기반 커스텀 제어 PCB의 설계와 제작, ATmega128 저수준 펌웨어, 센서 필터 파이프라인
  • 동작 방식: 완전 자율 주행이 아니라, 사용자가 조이스틱으로 직접 주행하고 노트북 UI의 방향·거리 안내를 참고하는 수동 주행 기반 측정 보조 시스템입니다.

2. 시스템 구성

노트북에서 도는 Python 고수준 처리부와 ATmega128 저수준 제어부를 UART로 연결해 역할을 나눴습니다.

구분 부품 역할
제어부 ATmega128 센서값 수집, PWM 제어, UART 통신
상위 연산부 노트북 (Python, OpenCV) RealSense 처리, PointCloud, Costmap, A* 경로 검증, UI
비전 센서 Intel RealSense D457 RGB 영상과 Depth 기반 3D 지형 데이터
자세 센서 MPU6050 (I2C) Roll/Pitch 측정, PointCloud 기울기 보정
거리 센서 HC-SR04 + SG90 서보 근거리 거리 측정과 높이 스캔
구동 피드백 모터 엔코더 4개 바퀴 회전량과 이동 거리 추정
토양 센서 FSR 압력 센서, 토양 수분 센서 지면 단단함과 수분 상태 측정
액추에이터 DC 모터, MG996R 서보, 부저 주행, 스탬프 모듈 구동, 완료 알림

데이터 흐름은 센서 → ATmega128 → UART → 노트북(Python) → UI 입니다. 노트북은 SERVO, TURN, STRIKE, BUZZER 명령을 보내고, ATmega128은 IMU, ENC, ULTRA, FORCE, WATER, RESULT 값을 돌려줍니다.

3. 내가 맡은 일

커스텀 제어 PCB 설계와 제작

브레드보드와 얇은 점퍼 와이어로는 모터 4개와 서보의 고전류 피크, 모터 노이즈가 엔코더와 아날로그 센서 신호를 흔드는 문제를 감당하기 어렵다고 판단해, Altium Designer로 전용 제어 PCB를 직접 설계하고 제작했습니다.

  • MCU: ATmega128A와 16MHz 크리스탈. 하드웨어 UART 2개와 풍부한 타이머로 4축 엔코더 카운팅과 여러 PWM 출력을 맡습니다.
  • 전원: 배터리(11.1~12.6V)를 스위칭 레귤레이터 LM2596XS로 5V로 낮춰 센서와 서보 전원으로 씁니다.
  • USB-UART: 노트북 연결에는 FT231XS를 쓰고, 모터 서지 노이즈 환경을 고려해 통신 속도를 9600bps로 낮춰 안정성을 우선했습니다.
  • VBUS 전원 격리: 노트북 USB-C의 5V와 보드의 메인 5V 라인을 물리적으로 분리했습니다. 두 전원이 충돌해 노트북 포트가 손상되거나 역전류(백피딩)가 흐르는 일을 막고, USB-C만 꽂으면 시리얼 칩만 깨어나고 메인 전원이 들어와야 MCU가 동작하는 구조입니다.
  • AVCC 필터: ADC 전원 핀 옆에 저항과 0.1µF 커패시터로 LC 저역 통과 필터를 두어 디지털 스위칭 노이즈가 토양 수분, 압력 센서의 아날로그 입력에 섞이지 않게 했습니다.
  • RESET 보호: 전원이 꺼질 때 리셋 라인 커패시터의 잔류 전하가 MCU로 역류하지 않도록 리셋과 VCC 사이에 고속 스위칭 다이오드(1N4148W)를 배치했습니다.

제작과 하드웨어 디버깅

  • Gerber 파일로 PCB를 발주하고, 작은 SMD 부품들을 핀셋과 리워크 스테이션으로 직접 수작업 납땜했습니다.
  • 2단계 전원 디버깅: 전원 투입 전에 멀티미터로 VCC-GND 쇼트를 전수 확인했습니다. 이어 파워 서플라이를 12V에 전류 제한 0.1A로 걸어 처음 전원을 넣었고, 이상이 없음을 확인한 뒤 제한을 풀자 무부하 대기 전류가 약 30mA로 안정됐습니다.
  • v1에서 v2로: v1 기판은 GND와 VCC가 쇼트난 채로 발주됐습니다. 원인을 찾아보니 모터 드라이버 쪽 라우팅 폭(route width)이 너무 두꺼워서 생긴 쇼트였습니다. 배선을 더 깔끔하게 다시 배치하고 via도 고쳐 2차(v2) 발주에서는 문제없이 정상 동작했습니다.
  • 하드웨어 루프백 검증: MCU를 올리기 전에 MCU_TXD와 MCU_RXD 패드를 핀셋으로 쇼트해 두고 Tera Term(9600bps)으로 문자를 보내, 보낸 데이터가 그대로 돌아오는 것으로 FT231XS 통신 경로를 확인했습니다.

ATmega128 저수준 펌웨어

주기가 다른 태스크로 나눈 타이머 기반 구조입니다.

  • 10ms 태스크: IMU, ADC 센서(압력, 토양 수분), 엔코더 속도 계산과 필터 갱신
  • 60ms 태스크: 초음파 센서 측정(센서끼리의 간섭을 피하려고 독립 시퀀스로 구동)
  • 200ms 태스크: 필터를 거친 값을 IMU,roll,pitch 같은 UART 패킷으로 노트북에 전송
  • 엔코더: 0.1ms 타이머 인터럽트에서 핀 상태 변화를 XOR해 4개 바퀴의 라이징 엣지 틱을 카운트
  • 초음파: Echo 펄스 폭을 타이머로 측정하고 타임아웃 가드를 두었으며, 20ms 간격으로 3회 측정해 평균낸 뒤 중앙값 필터를 적용
  • UART 프로토콜: ENC,lf,lb,rf,rb, ULTRA,distance, FORCE,value, WATER,value 같은 텍스트 패킷으로 정의

센서별 필터 파이프라인

센서마다 노이즈 특성이 달라 필터를 다르게 골랐습니다.

센서 문제 적용한 필터
MPU6050 IMU 가속도계는 진동에 약하고 자이로는 드리프트가 쌓임 칼만 필터(Roll/Pitch)로 융합
바퀴 엔코더 속도로 미분할 때 양자화 오차와 모터 리플 8개 창 이동 평균 필터
HC-SR04 초음파 반사면에 따라 값이 튀거나 사라지는 스파이크 3회 평균 후 3개 창 중앙값 필터
FSR 압력 센서 무부하에서도 남는 오프셋, 접촉 순간의 임펄스 초기 영점 보정 + 8개 창 이동 평균
토양 수분 센서 접촉 순간 임피던스 변동, 모터 GND 리플 8개 창 이동 평균 + 비트 시프트 기반 저역 통과 필터

토양 수분 센서의 저역 통과 필터는 8비트 AVR의 나눗셈 부담을 피하려고 실수 연산 대신 3비트 우측 시프트(÷8) 로 구현했습니다.

4. 팀원이 맡은 부분 (상위 소프트웨어와 기구)

  • 기구: Inventor로 상하부 플레이트, 센서 브래킷, 서보 고정부, 초음파 센서 장착부를 설계했습니다. 서보의 회전 운동을 링크 구조로 수직 직선 운동으로 바꾸는 스탬프 모듈(MG996R, 압축 스프링)로, 필요할 때만 FSR 압력 센서와 토양 수분 센서가 지면에 닿게 했습니다.
  • 지형 분석: RealSense Depth를 PointCloud로 바꾸고 IMU Roll/Pitch로 기울기를 보정한 뒤, BEV Height Map과 Costmap을 만들고 A* 경로를 미리 확인합니다.
  • 목표 추적과 UI: 사용자가 화면에서 목표를 클릭하면 Vision Tracker가 추적하며 LEFT, RIGHT, FORWARD 안내를 줍니다. OpenCV UI가 카메라, 지형 맵, 측정 결과를 보여 줍니다.

5. 시연 흐름

목표 선택 → 조이스틱 주행 → Height Scan → TURN → STRIKE → 결과 표시

  1. UI에서 목표 지점을 클릭하면 추적을 시작하고, 50cm 이상에서는 RealSense와 엔코더로 거리를 갱신합니다.
  2. 40~50cm 근접 구간부터는 초음파 센서와 서보로 목표 방향을 맞추고, Depth 카메라가 못 보는 근거리를 초음파로 보완합니다.
  3. 도착 후 Height Scan으로 SG90 서보가 초음파 센서 각도를 바꿔 가며 높이를 측정합니다.
  4. TURN으로 스탬프 모듈을 측정 위치로 돌리고, STRIKE로 내려 압력과 수분 값을 읽습니다.
  5. 두 값이 모두 정상으로 들어오면 UI에 END를 표시하고 부저로 완료를 알립니다.

7. 한계와 향후 방향

  • 초음파 센서: 반사면의 재질, 각도, 거리에 따라 값이 튀거나 아예 안 들어오는 경우가 있었습니다. 타임아웃 처리, 원본값 기반 판단, 변화량 기반 경계 판단으로 보완했고, 센서값을 무조건 필터링하기보다 상황에 따라 원본값을 쓰는 편이 나을 때도 있었습니다.
  • 측정 편차: 압력 센서는 접촉 위치와 누르는 힘, 토양 수분 센서는 토양 밀도와 삽입 깊이에 따라 값이 달라집니다. 센서별 캘리브레이션과 반복 측정 평균화가 필요합니다. 스탬프 모듈도 링크 유격과 스프링 강성에 따라 달라지므로 접촉력 보정, 리니어 가이드, 리밋 스위치를 추가할 수 있습니다.
  • 수동 주행: 구현 안정성과 시연 가능성을 위해 수동 주행으로 했고, 지금의 Costmap과 Vision Tracker 결과로 자동 속도 제어, 정렬, 정지를 추가하면 반자율 로버로 확장할 수 있습니다.

실제 센서 기반 로봇에서는 이론값과 달리 노이즈, 튐 현상, 지연, 통신 불안정이 생기고, 이를 고려한 예외 처리와 상태 관리가 중요하다는 점을 확인했습니다.

8. 회고

PCB를 발주할 때 v1은 GND와 VCC가 쇼트난 상태였고, 원인은 모터 드라이버 쪽 라우팅 폭이 너무 두꺼웠던 것이었습니다. 배선을 조금 더 깔끔하게 배치하고 via를 수정해서 2차 발주에서는 문제없이 정상 동작했습니다. 회로 발주와 펌웨어, 기능 구현을 반드시 마쳐야 하는 일정이 있어서, 배송 기간까지 고려하면 마음을 졸였습니다.
